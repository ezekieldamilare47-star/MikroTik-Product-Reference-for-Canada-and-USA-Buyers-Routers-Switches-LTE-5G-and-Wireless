## 1. Glossary

| Term | Meaning |
|---|---|
| RouterOS | MikroTik's operating system for routing, switching, wireless and security |
| CCR | Cloud Core Router, built for high-traffic networks |
| CRS | Cloud Router Switch, a switch with routing features |
| PoE | Power over Ethernet: power and data over one cable |
| SFP / SFP+ | Ports for fiber or copper modules (SFP+ supports higher speeds) |
| LTE / 5G | Connecting over mobile networks |

### Example Deployment Patterns

**Small office (up to 10 users)**
- One all-in-one router with Wi-Fi (hAP series)
- Optional LTE router for backup

**Mid-size office (10-50 users)**
- Dedicated router (RB4011 or L009)
- CRS switch with PoE for access points and phones
- Indoor wireless sized to floor area
- LTE/5G backup (Chateau LTE7 ax)

**Multi-site business**
- Same router and switch models at every site
- Shared configuration templates
- One spare unit per model held centrally
- Cellular backup at each location

**ISP or WISP (wireless ISP)**
- Cloud Core Router at the core (CCR2116 or CCR2216)
- CRS switching with SFP+ fiber uplinks
- Outdoor wireless and point-to-point links (OmniTIK, Mimosa)
- Volume purchasing through MikroTik wholesale arrangements

### Pre-Order Planning Notes

- Count PoE ports needed for access points and outdoor units
- Choose fiber or copper modules for each SFP+ port
- Check LTE/5G signal strength at each site before ordering cellular units
- Confirm delivery country (Canada or USA) for each site
- Record model numbers exactly; MikroTik model names encode ports and features
